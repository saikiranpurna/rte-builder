# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-22

### Added
- Initial release of rte-builder
- Complete WYSIWYG editor based on TipTap
- Full text formatting support (bold, italic, underline, strike, code)
- Font family and font size selection
- Text color and background color (highlight)
- Text alignment (left, center, right, justify)
- Lists (bullet and numbered)
- Headings (H1-H6)
- Blockquotes
- Links with auto-formatting
- Image insertion with custom media picker support
- Video insertion with custom media picker support
- Tables with resizing
- Code blocks with syntax highlighting (190+ languages)
- Inline code formatting
- Subscript and superscript
- Horizontal rules
- Character counter with limit support
- Undo/redo functionality
- Placeholder text
- Read-only mode
- Disabled mode
- Three toolbar presets: full, medium, simple
- Custom toolbar configuration
- TypeScript support with full type definitions
- Responsive design
- Custom styling support
- Comprehensive documentation
- Example code for common use cases

### Features
- Zero licensing costs (MIT license)
- React-first architecture
- Full TypeScript support
- Modern and lightweight (~300KB)
- Customizable toolbar
- Media picker integration
- Syntax highlighting for code blocks
- Character counting
- Auto-focus support
- Imperative API via refs

### Documentation
- README with installation and usage guide
- EXAMPLES with 12+ practical examples
- API reference documentation
- Migration guide from Froala
- Contributing guidelines
